## Descrição completa

```
O app oficial do Desafio Solar Brasil, a competição de barcos movidos a energia solar.

MAPA AO VIVO
Veja onde está cada embarcação durante as provas, com velocidade e posição
atualizadas em tempo real.

TRANSMISSÃO
Assista à live do evento em tela cheia ou em janela flutuante, sem parar de
acompanhar o mapa.

CHAT DO EVENTO
Converse com quem está acompanhando a competição. Envie fotos, vídeos e
arquivos, e reaja às mensagens.

FANTASY
Escolha três barcos para cada prova e marque um deles como pontuação dobrada.
Dá para mudar a escalação até a largada. A cada resultado publicado, a
classificação geral é atualizada.

AVISOS
Receba um lembrete uma hora antes de cada prova e outro na largada.

Navegar pelo app é livre. A conta (Google ou Apple) só é necessária para
escrever no chat e jogar o fantasy.
```

## Segurança dos dados (Play) e Privacidade (Apple)

Dados coletados, todos **vinculados à identidade** do usuário:

| Dado | Para quê | Obrigatório |
| --- | --- | --- |
| Nome e foto do perfil | Identificar quem fala no chat | Só para quem faz login |
| E-mail | Identificar a conta | Só para quem faz login |
| Mensagens e arquivos do chat | Funcionalidade do app | Só o que a pessoa envia |
| Identificador do aparelho (token de push) | Enviar os avisos das provas | Não |

- Não há publicidade, rastreamento entre apps nem venda de dados.
- Dados em trânsito são criptografados (HTTPS).
- A pessoa pode excluir a conta dentro do app (Configurações → Excluir conta).

## Conteúdo gerado por usuários (exigência das duas lojas)

O chat tem: denúncia de mensagem, bloqueio de usuário, exclusão da própria
mensagem e exclusão de conta. A moderação é feita pela organização do evento.
